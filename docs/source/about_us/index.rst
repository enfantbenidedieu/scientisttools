========
About Us
========

scientisttools is an open source `Python <https://www.python.org/>`_ library dedicated to Multivariate Exploratory Data Analysis, Clustering Analysis and Multidimensional Scaling. 
It was created in :math:`2023`. scientisttools will always be :math:`100\%` open source software and free for all to use.
It is released under the liberal terms of the `MIT Licence <https://github.com/enfantbenidedieu/scientisttools/blob/main/LICENSE>`_. 

It is developed in the open on `GitHub <https://github.com/enfantbenidedieu/scientisttools>`_.
